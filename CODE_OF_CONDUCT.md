# Code of Conduct

This project expects respectful, constructive participation.

## Expected Behavior

- Be direct and kind.
- Focus criticism on code, behavior, and outcomes.
- Assume contributors are participating in good faith unless there is clear evidence otherwise.
- Respect maintainers' decisions on project scope and implementation tradeoffs.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeated off-topic or bad-faith participation.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants who violate this code of conduct.
